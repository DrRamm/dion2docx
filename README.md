# Dion Chat → DOCX

Расширение для Chrome: сохраняет открытый диалог на `dion.vc` в файл **DOCX** —
кто, что и во сколько написал, плюс встроенные картинки.

## Зачем

Историю переписки из веб-чата dion.vc нельзя выгрузить штатно, а вручную
копировать сообщения и картинки долго. Расширение делает это в один клик и
складывает всё в один документ Word.

## Что делает

- Само прокручивает историю и подгружает **все** сообщения диалога.
- Для каждого сообщения сохраняет: **автора, дату и время** (точное, из
  метаданных), **текст**, **блок ответа** (reply) и **вложения-картинки**.
- Встраивает картинки прямо в документ (не ссылками).
- Скачивает готовый `.docx` в «Загрузки».

Формат — простой лог:

```
[01.01.2026 12:00:00] Иван Иванов: <текст сообщения>
↪ <автор цитируемого>: <текст цитаты>
<картинка>
```

## Установка

### Вариант 1: готовый zip (без Node.js)

1. Взять архив `release/dion-chat-docx-<версия>.zip` (или собрать его, см. ниже).
2. Распаковать в любую постоянную папку (папку потом не удалять — Chrome грузит
   расширение прямо из неё).
3. Открыть `chrome://extensions`.
4. Включить **Режим разработчика** (справа вверху).
5. Нажать **Загрузить распакованное расширение** и выбрать **распакованную
   папку** (внутри неё должен лежать `manifest.json`).
6. Обновить вкладку с `dion.vc` (F5), если она была открыта раньше.

### Вариант 2: из исходников (для разработки)

Нужен Node.js.

```sh
npm install
npm run build   # собирает dist/
```

Далее в Chrome — те же шаги 1–4 выше, но на шаге 5 выбрать папку `dist/`.
Папку `src/` загружать нельзя: её `content.js` содержит `import` и не работает
как content script до сборки.

## Сборка релиза

```sh
npm run release
```

Собирает `dist/` и упаковывает его в `release/dion-chat-docx-<версия>.zip`
(`manifest.json` в корне архива). Версия берётся из `src/manifest.json`.

## Автотесты

```sh
npm test                 # Chromium: popup → content script → DOCX
npm run test:yandex:dom  # Яндекс.Браузер: сбор диалога и DOCX
```

Тесты используют локальный диалог без аккаунта Dion. Проверяются виртуальная
прокрутка, ответы, время, картинки и скачанный DOCX.

Для полной проверки расширения в Яндекс.Браузере один раз выполните
`npm run setup:yandex` и загрузите папку `dist/` через «Load unpacked» в
открывшемся `chrome://extensions/`. Затем запускайте `npm run test:yandex`.
Используется отдельный профиль `~/.cache/dion-chat-docx/yandex-test`;
обычный профиль браузера не меняется. При другом расположении браузера или
профиля задайте `YANDEX_BINARY` и `YANDEX_PROFILE`.

Если браузер не запустил content script автоматически, расширение попробует
загрузить его на вкладку Dion после нажатия кнопки. Если это не удалось,
popup покажет причину ошибки браузера. После обновления расширения в
`chrome://extensions/` подтвердите новые разрешения и повторите экспорт.

## Использование

1. Открыть нужный диалог на `dion.vc`.
2. Нажать иконку расширения → **Экспортировать в DOCX**.
3. Прогресс показывается в правом нижнем углу страницы. Во время экспорта
   страница сама прокручивается — это нормально. Файл появится в «Загрузках».

## Разрешения

- `downloads` — сохраняет готовый DOCX в «Загрузки» через API Chrome.
- `offscreen` — создаёт временный blob URL для DOCX: фоновый service worker
  Manifest V3 не поддерживает `URL.createObjectURL()`.
- `scripting` и доступ к `https://dion.vc/*` — запускают сборщик на открытой
  вкладке, если браузер не внедрил content script автоматически.
- `content_scripts.matches: https://dion.vc/*` — запускает сбор сообщений
  только на страницах Dion. Доступ к другим сайтам не запрашивается.

## Ограничения

- Экспортируется только **открытый** диалог (не весь список чатов).
- Экспорт идёт прокруткой, но картинки читаются параллельно: небольшие диалоги
  (десятки сообщений) сохраняются за 1–3 секунды, длинные — дольше.
- Загружаются только **картинки**. Голосовые, видео и файлы-документы
  пропускаются (в документе помечаются как «вложение недоступно»).
- Если dion.vc сменит вёрстку, селекторы в `src/content.js` (объект `S`) нужно
  поправить.
- Работает только на домене `dion.vc` и требует входа в аккаунт в браузере.

# Docs index

Read this file when you do not know which file to open.

| File | Open it when |
| --- | --- |
| `docs/architecture.md` | You change the export path, the popup, the service worker, the offscreen page, or the DOCX build. |
| `docs/dom.md` | You change selectors, scroll, message fields, or images. |
| `docs/build.md` | You change `build.mjs`, `scripts/release.mjs`, or the manifest copy. |
| `docs/test.md` | You change tests or you check a change. |
| `docs/rules.md` | You add a permission, a dependency, or a selector. |

`AGENTS.md` holds the commands and the hard rules.
`README.md` is the Russian user guide.
`README.en.md` is the English user guide.

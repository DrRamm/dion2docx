# Текст для Chrome Web Store

English: [store-listing.en.md](store-listing.en.md).

Dion Chat → DOCX сохраняет открытый диалог на dion.vc в документ Word (.docx).

В документ входят:

- Авторы и время сообщений в часовом поясе компьютера.
- Текст с переносами строк.
- Ответы с цитатами.
- Изображения.

Для экспорта откройте диалог, нажмите значок расширения и кнопку скачивания. Расширение прокрутит историю, соберёт доступные сообщения и сохранит документ в папку «Загрузки». Название файла содержит название чата и дату.

Обработка выполняется локально в браузере. Расширение не отправляет переписку на сторонние серверы и не использует аналитику.

Экспортируется только открытый диалог. Голосовые сообщения, видео и вложения, кроме изображений, не включаются. Полнота истории зависит от сообщений, которые удалось загрузить на странице.
